# Meu Ponto

Versões publicadas do **Meu Ponto**, widget para Windows que calcula os horários do ponto (almoço, volta e saída), mostra lembretes e acompanha o banco de horas.

- Para instalar: baixe o **Instalar-Meu-Ponto.exe** na versão mais recente (em *Releases*).
- O manual de uso está no arquivo **Manual-Meu-Ponto.pdf** de cada versão.
- Os widgets instalados se atualizam sozinhos. Cada versão é assinada digitalmente, e o programa recusa arquivos sem a assinatura.
